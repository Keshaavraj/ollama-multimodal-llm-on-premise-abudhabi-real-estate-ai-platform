# Old Versions - Archive

This folder contains early development versions of the chatbot for reference.

## Files

### chatbot.py
- Simple console-based chatbot
- Uses Ollama directly without API
- Good for quick testing
- Run: `python chatbot.py`

### streamlit_app_requirements.txt
- Requirements for early Streamlit prototypes
- Basic dependencies without advanced features

## Note

These are archived versions. For current implementation, use:
- **Streamlit Version**: `../streamlit-version/`
- **React Version**: `../react-version/`

## Why Archived?

These files were early prototypes before the project was restructured into:
1. Professional documentation
2. Separate Streamlit and React versions
3. Comprehensive feature set

Kept here for reference and development history.
